Setup required: connect to Google Sheets to see submissions.
  1. Create a new Google Sheet
  2. Go to Extensions > Apps Script
  3. Paste the code from apps-script.gs
  4. Click Deploy > New deployment > Web app
  5. Set access to "Anyone" and deploy
  6. Copy the URL and paste it in SCRIPT_URL at the bottom of this page and in index.html
